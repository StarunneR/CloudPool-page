在 LTSC 版本中安装 Microsoft store

适用于 Windows 11 LTSC 2024 和 Windows 10 LTSC 2021。

  • 确保联网；以管理员打开 PowerShell。
  • 运行： wsreset -i
  • 等待通知提示 Store 已安装（可能需几分钟）。

在 Windows 10 LTSC 2021 可能出现找不到 cliprenew.exe 的错误，忽略即可。

推荐安装 应用安装程序 (App Installer)（包含 WinGet），便于安装其他 .appx 包。

若官方渠道失败，可使用社区提供的替代包（例如 abbodi1406 的 GitHub release）。

操作说明

方法2：Ventoy （高级用户）

用于配置多系统启动U盘

目标电脑：设置从 U 盘安装介质启动

1. 进入一次性启动菜单或 BIOS/UEFI

  • 先插入 U 盘，然后重启（某些主板在开机自检前才能识别 USB）。
  • 一次性启动菜单（优先推荐，改动小、风险低）：在开机画面连续敲某个热键进入。常见热键：F12 / F11 / Esc / F9（厂商不同）。进入后直接选择带有 USB 或 UEFI: <厂商名> 前缀的项启动。
  • 进入 BIOS/UEFI 设置（需要长期修改启动顺序）：常见热键：Del / F2。进入后用键盘或鼠标导航到 Boot、Boot Order/Boot Priority、或 Boot Options。

2. 在菜单中选择 U 盘或修改启动顺序

  • 一次性菜单：选项通常显示为 UEFI: SanDisk、USB HDD、Removable Device 等。

    • 若要确保使用 UEFI 引导，选择前缀带 UEFI: 的项。

  • 在 BIOS/UEFI 中改顺序：

    • 找到 Boot → Boot Option #1 / Boot Priority，把 USB/Removable 放到第一位。
    • 现代 UEFI 常有 Boot Override（或“Boot Now”）功能：直接从列表里点一次性覆盖启动项，避免永久改顺序。

  • 保存并退出：常见快捷键 F10 或选择 Save & Exit。电脑会按新顺序重启。

3. 常见兼容与安全设置（若 U 盘无法启动时检查）

  • Secure Boot：若 U 盘不是签名的 UEFI 引导，Secure Boot 可能阻止启动。路径通常在 Security 或 Boot 下，操作：暂时禁用 Secure Boot 或把 OS Type 改为 Other/Legacy。完成安装后可恢复启用。
  • CSM / Legacy Boot（Compatibility Support Module）：若你的 U 盘是旧的 MBR/Legacy 引导，需启用 CSM/Legacy Support或把 Boot Mode 设置为 UEFI and Legacy / Legacy。注意：把系统从 UEFI 切到 Legacy 可能导致已有操作系统无法启动，优先使用一次性启动菜单或 Boot Override。
  • Fast Boot / USB initialization：某些主板开启 Fast Boot 会跳过 USB 初始化，导致识别不到 U 盘。若检测不到 U 盘，临时禁用 Fast Boot 或插到后置 USB 2.0 口再试。
  • 端口与媒体：若仍无法识别，尝试换 USB 插口（优先后置或 USB 2.0），或在另一台电脑确认 U 盘是否可启动。

短检查表：插好 U 盘 → 重启按 F12（或厂商对应键）尝试一次性启动 → 若看不到 U 盘，进 BIOS 检查 Boot Priority / Boot Override → 如仍失败，检查 Secure Boot / CSM / Fast Boot / USB 端口。

Windows 激活

  1. Microsoft Activation Scripts (MAS)

    · For Windows 8, 10, 11: (PowerShell)

     irm https://get.activated.win | iex

    · OR (If the above is blocked (by ISP/DNS), try this (needs updated Windows 10 or 11):)

     iex (curl.exe -s --doh-url https://1.1.1.1/dns-query https://get.activated.win | Out-String)

    · OR For Windows 7 and later: (PowerShell)

     iex ((New-Object Net.WebClient).DownloadString('https://get.activated.win'))
